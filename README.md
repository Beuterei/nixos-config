# nixos-config

NixOS flake for **helios**: GNOME desktop, NVIDIA, Docker, and a single-node k3s cluster. Nixpkgs and home-manager.

## Layout

| Path | Role |
| --- | --- |
| `flake.nix` | Inputs and `nixosConfigurations.helios` |
| `lib/mksystem.nix` | Builds a system from `machines/<host>.nix` and `users/<user>/` |
| `machines/helios.nix` | Host config |
| `machines/hardware/helios.nix` | Generated disks and CPU. Do not hand-edit |
| `users/<user>/nixos.nix` | Account, groups, SSH key |
| `users/<user>/home-manager.nix` | Git and SSH client |
| `Taskfile.yml` | `check`, `test`, `switch` |
| `flake.lock` | Pinned inputs. Generated by Nix |

## Resetup helios

Reinstall this flake onto the existing helios disks. Do not repartition. Boot a NixOS ISO in UEFI mode and connect to the network. The ISO only has to be recent enough to run `nixos-install --flake`.

1. Mount the root and EFI partitions from `machines/hardware/helios.nix`:

   ```sh
   sudo mount /dev/disk/by-uuid/a2792c6e-6e1d-439b-b71c-12dc793771e4 /mnt
   sudo mkdir -p /mnt/boot
   sudo mount /dev/disk/by-uuid/B05C-C38A /mnt/boot
   ```

   If those UUIDs are gone because the disk was reformatted, set the new ones from `blkid` in `machines/hardware/helios.nix` before installing.

2. The repo must be at `/mnt/srv/nixos-config` (that is `/srv/nixos-config` after reboot). If the mount does not already have it, copy it there. If the copy is a git checkout, `git add` any untracked files first. Flakes ignore them.

3. Install. The ISO may need flakes enabled. `nixos-install` asks for a root password.

   ```sh
   export NIX_CONFIG="experimental-features = nix-command flakes"
   sudo nixos-install --root /mnt --flake /mnt/srv/nixos-config#helios
   ```

4. The account has an SSH key and no login password. Set one so GDM can log in. `<user>` is the `user` value in `flake.nix`. The password is mutable, so this survives later rebuilds.

   ```sh
   sudo nixos-enter --root /mnt
   passwd <user>
   ```

5. `sudo reboot` and log in on GDM.

6. Nix does not store login secrets. Do these once if the home directory was empty:

   - Wi-Fi, if NetworkManager has no saved connection.
   - GitHub over SSH. The private key stays at `~/.ssh` and is not part of this repo.
   - SOPS age key:

     ```sh
     mkdir -p ~/.config/sops/age
     echo 'AGE-SECRET-KEY-1...' > ~/.config/sops/age/keys.txt
     chmod 600 ~/.config/sops/age/keys.txt
     ```

7. From the installed repo:

   ```sh
   cd /srv/nixos-config
   task switch -- helios
   ```

## Rebuild

On a machine that is already installed:

```sh
cd /srv/nixos-config
task check -- helios    # evaluate only
task test -- helios     # activate, do not change the boot default
task switch -- helios   # activate and set the boot default
```
